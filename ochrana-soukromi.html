Ochrana soukromí

Web NeVOLE nemá registraci, kontaktní formulář, veřejný kontaktní e-mail, analytiku, reklamní systémy ani vlastní cookies. Provozovatel prostřednictvím webu osobní údaje návštěvníků nesbírá.

1. Co web sám zpracovává

NeVOLE je statická informační stránka. Neumožňuje založení účtu, odeslání formuláře, přidání komentáře ani přímý kontakt s provozovatelem. Zdrojový kód webu neodesílá provozovateli žádné osobní údaje návštěvníků.

2. Návštěva webu a hosting

Web je publikován prostřednictvím služby GitHub Pages. Poskytovatel hostingu GitHub může při návštěvě zaznamenat IP adresu a další nezbytné technické údaje zejména pro zabezpečení a provoz své služby. Provozovatel projektu k těmto technickým záznamům nemá prostřednictvím tohoto webu přístup. Zpracování u GitHubu se řídí jeho vlastními pravidly.

Informace GitHub Pages o sběru dat ↗ · Zásady soukromí GitHub ↗

3. Cookies a podobné technologie

Zdrojový kód webu NeVOLE nenastavuje vlastní cookies ani nepoužívá analytické, reklamní nebo profilovací nástroje. Proto se na webu nezobrazuje cookie lišta. Případná technická opatření používaná poskytovatelem hostingu se řídí jeho vlastními pravidly.

4. Předávání a využití údajů

Provozovatel projektu prostřednictvím webu žádné osobní údaje návštěvníků nezískává, neprodává ani nepředává politickým stranám, reklamním systémům nebo jiným příjemcům. Technické údaje související s hostingem zpracovává GitHub podle svých zveřejněných podmínek.

5. Vaše práva

V otázkách technických údajů zaznamenaných službou GitHub Pages se můžete obrátit přímo na GitHub podle jeho zásad soukromí. Máte také právo podat stížnost u Úřadu pro ochranu osobních údajů ↗.

6. Automatizované rozhodování

Web NeVOLE neprovádí automatizované rozhodování ani profilování.

7. Změny těchto informací

Text aktualizujeme, pokud se změní fungování webu, poskytovatel hostingu nebo právní požadavky. Aktuální znění je vždy zveřejněno na této stránce.
